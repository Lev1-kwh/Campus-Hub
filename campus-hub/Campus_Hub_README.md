# Campus Hub

## 1. 项目简介

Campus Hub 是一个基于 Spring Boot 开发的校园社区后端系统。

项目主要面向高校学生用户，实现用户认证、校园帖子发布、帖子浏览、点赞、评论以及权限控制等核心社区功能。

系统采用 Spring Boot + MyBatis-Plus + MySQL 技术栈开发，通过 JWT
实现用户身份认证，并使用拦截器完成接口访问权限控制。

项目重点关注后端业务开发中的用户身份管理、多表关联操作、事务一致性以及
RESTful API 设计。

## 3. 项目架构

![image-20260826230909036](D:\Campus Hub\campus-hub\images\project-structure.png)

项目采用经典 MVC + 三层架构设计：

    Controller
        |
        ↓
    Service
        |
        ↓
    Mapper
        |
        ↓
    MySQL Database

### 分层职责

Controller: 负责接收 HTTP 请求、处理接口参数并返回响应。

Service: 负责核心业务逻辑处理，包括点赞、评论、权限校验以及事务控制。

Mapper: 基于 MyBatis-Plus 完成数据库访问操作。

Entity: 映射数据库表结构。

DTO: 用于接口请求和响应的数据传输。

Interceptor: 实现 JWT Token 校验和用户身份解析。

Exception: 统一处理业务异常。

## 5. 数据库设计

![database-design](D:\Campus Hub\campus-hub\images\database-design.png)

主要数据表：

### user 用户表

  字段       说明
---------- ----------
  id         用户ID
  username   用户名
  password   加密密码

### post 帖子表

  字段            说明
--------------- ------------
  id              帖子ID
  user_id         发布用户ID
  title           标题
  content         内容
  category        分类
  view_count      浏览量
  like_count      点赞数量
  comment_count   评论数量
  create_time     创建时间

### post_like 点赞表

  字段      说明
--------- --------
  id        记录ID
  user_id   用户ID
  post_id   帖子ID

通过联合唯一约束： `unique(user_id, post_id)`

保证同一用户不能重复点赞。

### comment 评论表

  字段      说明
--------- ----------
  id        评论ID
  user_id   评论用户
  post_id   所属帖子
  content   评论内容

## 6. 核心业务实现

## 6.1 JWT认证流程

![jwt-flow](D:\Campus Hub\campus-hub\images\jwt-flow.png)

用户登录：

    用户输入账号密码
            |
            ↓
    UserService校验用户信息
            |
            ↓
    生成JWT Token
            |
            ↓
    返回客户端

请求访问接口：

    JwtInterceptor拦截请求
    
    ↓
    
    解析JWT Token
    
    ↓
    
    获取用户ID
    
    ↓
    
    存入HttpServletRequest
    
    ↓
    
    Controller通过request获取当前登录用户
    
    ↓
    
    执行用户相关业务

------------------------------------------------------------------------

## 6.2 点赞业务设计

点赞流程：

    用户点击点赞
    
            ↓
    
    查询用户是否已经点赞
    
            ↓
    
    不存在:
        创建点赞记录
        like_count + 1


    存在:
        删除点赞记录
        like_count - 1

使用 `@Transactional` 保证：

-   点赞记录
-   帖子点赞数量

两个操作保持一致。

------------------------------------------------------------------------

## 6.3 评论业务设计

发表评论：

    创建评论记录
    
            ↓
    
    comment表插入数据
    
            ↓
    
    post表comment_count + 1

删除评论：

    查询评论是否存在
    
            ↓
    
    校验评论作者权限
    
            ↓
    
    删除评论
    
            ↓
    
    comment_count - 1

------------------------------------------------------------------------

## 6.4 删除帖子事务设计

删除帖子：

    删除帖子
    
            ↓
    
    校验帖子存在
    
            ↓
    
    校验用户权限
    
            ↓
    
    删除相关点赞数据
    
            ↓
    
    删除相关评论数据
    
            ↓
    
    删除帖子数据

整个过程使用：

    @Transactional保证：
    post_like
    comment
    post
    三个表删除的一致性

保证多表数据一致性。

## 8. 项目亮点

- 基于Spring Boot + MyBatis-Plus搭建校园社区后端系统
- 使用JWT + Interceptor实现无状态登录认证
- 使用BCrypt进行用户密码加密存储
- 设计用户、帖子、评论、点赞多表关联模型
- 使用@Transactional保证点赞、评论、删除帖子等业务数据一致性
- 基于用户ID实现资源访问权限控制
- 使用统一异常处理规范接口错误返回
